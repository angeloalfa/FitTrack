# FitTrack Pro

Workout tracker PWA per Android/iOS. Funziona offline, salva i dati localmente e permette backup su file.

## Deploy su GitHub Pages

1. Carica tutti i file in questo repo
2. Settings → Pages → Source: `main` branch, `/ (root)`
3. Apri `https://angeloalfa.github.io/FitTrack/` da Chrome Android
4. Menu ⋮ → "Installa app"

## File

- `index.html` — app completa
- `sw.js` — service worker (offline)
- `manifest.webmanifest` — manifest PWA
- `icon.svg` — icona
- `.nojekyll` — disabilita Jekyll
